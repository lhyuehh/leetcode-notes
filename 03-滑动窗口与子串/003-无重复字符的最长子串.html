003. 无重复字符的最长子串（中等）

一句话核心：维护 [left .. right] 无重复子串窗口——要么用 set 账本在重复时让 left 一步步吐字符，要么用字典记上次下标直接把 left 跳到 last_idx[ch] + 1。

二、下次遇到怎么想？（简单 3 步）

  1. 看题型：求连续子串 + “无重复”有单调性（窗口扩只会更可能重复，缩只会更干净）→ 滑动窗口。

  3. 通用模板（推荐串联后续 438、76）：window = set()，遇重复就 while ch in window: 吐出 s[left] 并 left += 1。
  4. 本题加速版：last_idx = {} 记每个字符上次出现的下标，直接把 left 跳过去。
  5. 更新答案：求最长合法窗口，所以等窗口重新合法后，在外面更新 ans = max(ans, right - left + 1)。

三、我容易做错的地方（本次真实踩坑复盘）

使用“记下标跳 left 法”时踩过这 2 个坑：

  1. ❌ 以为必须删除字典里 left 之前的旧记录
  2. 其实完全不用删！只要判断 last_idx[ch] >= left（或者直接写 left = max(left, last_idx[ch] + 1)），left 之前的旧下标会被自动忽略，而且 left 绝不会倒退。
  3. ❌ 在 else 分支里忘了把 last_idx[s[right]] 更新成最新 right（最隐蔽！）
  4. 比如 "bbbbb"：第 2 个 'b' 进了重复分支把 left 移到 1，但字典里的 'b' 还是旧的 0，到第 3 个 'b' 时误判 0 < left(1) 没重复，直接算错长度。
  5. ✅ 铁律：不管有没有发生重复，last_idx[s[right]] = right 必须写在 if/else 外面，每轮必更新！

四、标准代码（Python）

解法一：通用滑窗 set 版（最简洁，推荐通用母模板）

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()
        left = 0
        ans = 0
        for right, ch in enumerate(s):
            while ch in window:
                window.remove(s[left])
                left += 1
            window.add(ch)
            ans = max(ans, right - left + 1)
        return ans

解法二：记下标跳 left 版（一趟直跳）

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_idx = {}
        left = 0
        ans = 0
        for right, ch in enumerate(s):
            if ch in last_idx:
                left = max(left, last_idx[ch] + 1)
            last_idx[ch] = right  # 无论是否重复，每轮必更新！
            ans = max(ans, right - left + 1)
        return ans
  • 时间复杂度：O(n)
  • 空间复杂度：O(字符集大小)
