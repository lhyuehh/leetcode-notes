438. 找到字符串中所有字母异位词（中等）

一句话核心：目标子串长度固定为 k = len(p) → 用长度 k 的定长滑动窗口从左滑到右，实时比对窗口账本与 p 的频次是否一致。

一、我的极简写法 vs 标准定长滑窗

1. 我的极简写法（切片 + Counter(ch)）

from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        pdict = Counter(p)
        ans = []
        plen = len(p)
        for right in range(plen - 1, len(s)):
            ch = s[right - plen + 1 : right + 1]
            if Counter(ch) == pdict:
                ans.append(right - plen + 1)
        return ans
  • 为什么小用例跑得很快？：Counter(ch) 底层是 C 实现，省去了 Python 层的逐字符加减和删键操作，代码极短。
  • 潜在隐患（面试必知）：每轮都要重数一遍长度为 k 的切片，没有复用上一轮账本，时间复杂度是 O(n · k)；如果 s 长度 3×10⁴ 且 p 长度 1.5×10⁴，极端用例会超时（TLE）。

2. 标准定长滑窗（O(n)，进 1 出 1 复用账本）

什么叫“进 1 出 1 复用账本”？ 以 s = "cbac", p = "abc" 为例：第 1 格 [c, b, a] 已数好 {'c':1, 'b':1, 'a':1}；右滑到 [b, a, c] 时中间的 b, a 根本没动，不用重数，只需在原账本上改 2 笔——新来的 'c' +1、滑出去的 'c' -1。无论 p 多长，每格永远只改 2 次（O(1)）。

通用 Counter 版（支持任意字符集）

from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        k = len(p)
        cnt_p = Counter(p)
        cnt_s = Counter()
        ans = []
        for right, ch in enumerate(s):
            cnt_s[ch] += 1
            left = right - k + 1
            if left < 0:
                continue
            if cnt_s == cnt_p:
                ans.append(left)
            out = s[left]
            cnt_s[out] -= 1
            if cnt_s[out] == 0:  # 易错点：减到 0 必须删键！
                del cnt_s[out]
        return ans

极致速度版（26 格数组 [0] * 26）

class Solution:
    def findAnagrams(self, s: str, p: str) -> list[int]:
        k = len(p)
        cnt_p = [0] * 26
        for ch in p:
            cnt_p[ord(ch) - ord('a')] += 1

        cnt_s = [0] * 26
        ans = []
        for right, ch in enumerate(s):
            cnt_s[ord(ch) - ord('a')] += 1
            left = right - k + 1
            if left < 0:
                continue
            if cnt_s == cnt_p:
                ans.append(left)
            cnt_s[ord(s[left]) - ord('a')] -= 1
        return ans

二、易错点复盘

  1. ❌ 用 Counter 滑窗时，出窗减到 0 没删键：{'a': 1, 'x': 0} == {'a': 1} 为 False，必须 if cnt_s[out] == 0: del cnt_s[out]。
  2. ❌ 只用 Counter(切片) 忘了复杂度的坑：面试官追问“如果 p 也很长怎么办？”时，必须能立刻切回“进 1 出 1 复用账本”的 O(n) 写法。
