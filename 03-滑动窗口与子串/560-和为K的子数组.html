560. 和为 K 的子数组（中等）

一句话核心：数组含负数导致滑动窗口失效 → 改用 前缀和 + 哈希表，把问题转化为“前面出现过多少个等于 cur_sum - k 的前缀和”。

一、思路图解

二、下次遇到怎么想？（简单 3 步）

  1. 先判单调性：求连续子数组和，看到数据可能有负数或 0 → 滑动窗口立刻排除，转向前缀和 + 哈希表。
  2. 列等式（和 001. 两数之和 完全同源）：
  3. cur_sum - pre_sum == k ⟺ pre_sum == cur_sum - k
  4. 账本 prefix_cnt 记录：{前缀和数值: 它在左边出现过多少次}（等价于普通字典配合 .get(key, 0)）。
  5. 写循环（先查后存）：先累加 prefix_cnt[cur_sum - k]，再把 cur_sum 存进账本。

三、我容易做错的地方（本次真实踩坑复盘）

  1. ❌ 漏写初始化 prefix_cnt[0] = 1
  2. 含义：还没遍历任何元素前，“空前缀和为 0”天然出现过 1 次。
  3. 不写这行，所有从下标 0 就开始的合法子数组（比如 nums = [2, 1], k = 2 中的 [2]）都会漏掉！
  4. ❌ 查和存顺序写反（先存自己、再查表）
  5. 当 k = 0（如 nums = [1], k = 0）时，先执行 prefix_cnt[1] += 1 再查 prefix_cnt[1 - 0]，会把自己刚存进去的值查出来，把“空子数组”误算成答案。
  6. ✅ 铁律：和 001. 两数之和 一样，永远先查左边，再存自己！

四、标准代码（Python）

from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        prefix_cnt = defaultdict(int)
        prefix_cnt[0] = 1                 # 坑点 1：空前缀和为 0 出现 1 次
        cur_sum = 0
        ans = 0
        for x in nums:
            cur_sum += x
            ans += prefix_cnt[cur_sum - k] # 坑点 2：先查左边
            prefix_cnt[cur_sum] += 1       # 再存自己
        return ans
  • 时间复杂度：O(n)
  • 空间复杂度：O(n)
