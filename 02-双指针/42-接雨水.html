42. 接雨水（困难）

一句话核心：这道题是三大算法思想的交汇点——竖着算体现前后缀分解 → 双指针省空间，横着算体现单调栈填平凹槽。

一、思路图解（竖算 vs 横算 & 弹栈简化原理）

二、方法怎么串起来？（从暴力到三大解法的思维进化链）

  1. 起点：暴力竖着算（O(n²)）
  2. 对每根柱子 i，头顶水量 = min(左边最高, 右边最高) - height[i]。每列都往左往右扫一遍太慢。
  3. 进化 1：前后缀分解（O(n) 时间，O(n) 空间）—— 最符合直觉
  4. 注：这步不是双指针，而是教程里的“前后缀分解 / 备忘录预处理”（和后续 238. 除了自身以外数组的乘积 完全同源）！
  5. 从左往右预处理 pre_max[i]，从右往左预处理 suf_max[i]，最后逐列相减累加。
  6. 进化 2：相向双指针（O(n) 时间，O(1) 空间）—— 前后缀的压缩版
  7. 发现 pre_max 只从左往右涨、suf_max 只从右往左涨，于是用 left / right 两个指针和 left_max / right_max 两个变量替代两个数组，谁更小就先结算谁那一列。
  8. 平行路线：单调递减栈（O(n) 时间，O(n) 空间）—— 横着按层算
  9. 换个切法：不按列算，而是找凹槽，每次出栈相当于把凹槽填平、把图简化（和后续 739. 每日温度、84. 柱状图中最大的矩形 同源）。

三、核心病因复盘：为什么单调栈之前总写错？

  • 建模误区：总想在循环外写死一个 left = 0，以为整个图只有一堵固定左墙。
  • 真相（剥洋葱）：不同深度的坑左墙不同——弹出槽底 bottom = stack.pop() 之后，脚下露出的新栈顶 stack[-1] 才是这一层的左墙！
  • 4 个代码细节坑：
  • ❌ 入栈时提前算 relativewater（此时右墙未知）→ ✅ 只存下标 i。
  • ❌ height[i] > stack[-1] 忘了套 height[...] → ✅ 写 height[i] > height[stack[-1]]。
  • ❌ 把高度差起名叫 height 覆盖输入数组、宽度写成 +1 → ✅ 改名 dh，宽度是 i - left - 1。
  • ❌ 用 if / else 拆开导致当前柱子忘了入栈 → ✅ while 结算完统一 stack.append(i)。

四、标准代码（Python 三大流派对照）

1. 前后缀分解（竖着算最直觉版，串联 238 题）

class Solution:
    def trap(self, height: list[int]) -> int:
        n = len(height)
        pre_max = [0] * n
        pre_max[0] = height[0]
        for i in range(1, n):
            pre_max[i] = max(pre_max[i - 1], height[i])

        suf_max = [0] * n
        suf_max[-1] = height[-1]
        for i in range(n - 2, -1, -1):
            suf_max[i] = max(suf_max[i + 1], height[i])

        return sum(min(pre_max[i], suf_max[i]) - height[i] for i in range(n))

2. 相向双指针（竖着算省空间版，O(1) 空间）

class Solution:
    def trap(self, height: list[int]) -> int:
        left, right = 0, len(height) - 1
        left_max = right_max = ans = 0
        while left < right:
            left_max = max(left_max, height[left])
            right_max = max(right_max, height[right])
            if left_max < right_max:
                ans += left_max - height[left]
                left += 1
            else:
                ans += right_max - height[right]
                right -= 1
        return ans

3. 单调递减栈（横着算，串联 739、84 题）

class Solution:
    def trap(self, height: list[int]) -> int:
        stack = []  # 存下标，保持对应高度单调递减
        water = 0
        for i in range(len(height)):
            while stack and height[i] > height[stack[-1]]:
                bottom = stack.pop()
                if not stack:
                    break
                left = stack[-1]
                dh = min(height[left], height[i]) - height[bottom]
                length = i - left - 1
                water += dh * length
            stack.append(i)
        return water
