15. 三数之和（中等）

一句话核心：题目要返回去重后的数值而非原下标 → 先 sort() 创造“左小右大”并让相同数挨在一起，再用 for 固定第一位 + 相向双指针夹逼。

二、下次遇到怎么想？（简单 3 步）

  1. 为什么不用两数之和的哈希法？
  2. 哈希法去重很麻烦（要排序元组再丢进 set）；而本题只要数值不要下标，直接 nums.sort() 就能一边夹逼一边相邻去重。
  3. 拆成两数之和：
  4. 外层固定 nums[i]，内层在 [i + 1 .. n - 1] 放 start, end 找和为 -nums[i] 的两个数。
  5. 两处去重 + 一个剪枝：
  6. 剪枝：nums[i] > 0 直接 break；
  7. 外层去重：跳过与前一个相同的 nums[i]；
  8. 内层去重：命中答案后跳过相同的 nums[start] 和 nums[end]。

三、我常犯的思维问题 & 如何纠正

  1. ❌ 外层用 while 手动 i += 1，写着写着就漏掉推进导致死循环
  2. ✅ 纠正：外层永远用 for i in range(len(nums) - 2)，把步进交给 Python，去重全放循环开头用 continue。
  3. ❌ 内层“先走 1 步 + 再用 while 跟前一个比”容易漏掉固定前进、也搞不清顺序
  4. ✅ 纠正：改用 labuladong“先锁旧值法”——先记 left_val, right_val = nums[start], nums[end]，再用 while start < end and nums[start] == left_val: start += 1 一步到位完成前进 1 步 + 跳过重复。
  5. ❌ 写里层 while 时刹车条件放错边
  6. ✅ 纠正：铁律下标在左，取值在右（start < end and ...）。

四、最适合我的完整版代码（Python）

class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        result = []
        nums.sort()
        for i in range(len(nums) - 2):
            if nums[i] > 0:                     # 剪枝：最小数都 > 0，不可能凑出 0
                break
            if i > 0 and nums[i] == nums[i - 1]: # 外层去重：for + continue 永不死循环
                continue

            target = -nums[i]
            start, end = i + 1, len(nums) - 1
            while start < end:
                s = nums[start] + nums[end]
                if s > target:
                    end -= 1
                elif s < target:
                    start += 1
                else:
                    # 锁旧值法：一步到位完成前进 + 去重
                    left_val, right_val = nums[start], nums[end]
                    result.append([nums[i], left_val, right_val])
                    while start < end and nums[start] == left_val:
                        start += 1
                    while start < end and nums[end] == right_val:
                        end -= 1
        return result
  • 时间复杂度：O(n²)（排序 O(n log n) + 外层与内层双指针 O(n²)）
  • 空间复杂度：O(1)（不计排序栈空间与返回值）
