283. 移动零（简单）

一句话核心：不要遇到 0 就把后面整个数组往前搬（O(n²)）；反过来用同向快慢指针把非零数按顺序填到左边 slow 位置上，O(n) 一次搞定。

二、下次遇到怎么想？（简单 3 步）

  1. 看要求：要求原地修改 + 保持非零元素相对顺序 → 立刻锁定同向快慢指针（划界法）（不能用两端直接对换，否则会打乱顺序）。
  2. 定死两个指针含义：
  3. slow：守住“已整理好的非零区”右边界（下一个非零数该放的位置）；
  4. fast：从左到右探路，只挑非零数。
  5. 写代码：遇到 nums[fast] != 0，就把它换到（或覆盖到）nums[slow]，然后 slow += 1。

三、我容易做错的地方（重点避坑）

  1. ❌ 里层 while 忘写边界保护导致越界崩溃
  2. ✅ 铁律：先写刹车，再写条件（下标在左，取值在右） → while i <= j and nums[i] == 0:。能用单层 if 解决就绝不写嵌套 while。
  3. ❌ 整体搬移思路导致 pre 和 i 更新绕昏
  4. 搬移后原 i 处的元素已经挪到了 pre，如果还写 i += 1 会跳过新搬过来的元素。
  5. ✅ 不要跨轮次维护 pre；更推荐直接用下面的快慢指针模板，零额外状态变量。
  6. ❌ 末尾补零漏掉最后一个元素
  7. Python range(a, b) 是左闭右开，末尾补零右边界必须是 len(nums)，不是 len(nums) - 1。

四、标准代码（Python）

写法一：一趟交换版（最简洁）

class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow], nums[fast] = nums[fast], nums[slow]
                slow += 1

写法二：labuladong 两步覆写版（复用 27 题模板）

class Solution:
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]
                slow += 1
        for p in range(slow, len(nums)):
            nums[p] = 0
  • 时间复杂度：O(n)
  • 空间复杂度：O(1)
