11. 盛最多水的容器（中等）

一句话核心：从最宽边界（left = 0, right = n - 1）出发，高度被短板卡死；每次淘汰较矮的那一侧，用 ans = max(...) 记录沿途最大值。

二、下次遇到怎么想？（简单 3 步）

  1. 先写公式：area = (right - left) * min(height[left], height[right])。
  2. 找单调排除条件：
  3. 虽然柱子高度是无序的，但下标宽度 right - left 是从最大开始单调递减的！
  4. 对较矮的那根短板来说，它已经用上了“能配到的最大宽度”，且高度上限被自己卡死。再往里挪另一侧只会让宽度更小、高度更不大于它，所以短板剩下的所有配对全都不可能更优，放心淘汰！
  5. 写循环：while left < right 计算面积更新 ans，哪边矮就挪哪边（相等时挪任意一边都行）。

三、我容易做错的地方（思维陷阱复盘）

  • ❌ 陷入“下一步面积一定要比当前更大才移动”的爬山法陷阱
  • 总觉得往里走不知道里面是高是矮，万一面积变小了怎么办？
  • ✅ 正确心态：相向双指针不是“只往更大的方向走”，而是“把绝对没救的短板淘汰掉，保证不漏全局最优解”。就算这一步面积变小了也没关系，历史最大值已经安全锁在 ans 里了！

四、标准代码（Python）

class Solution:
    def maxArea(self, height: list[int]) -> int:
        left, right = 0, len(height) - 1
        ans = 0
        while left < right:
            area = (right - left) * min(height[left], height[right])
            ans = max(ans, area)
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
        return ans
  • 时间复杂度：O(n)
  • 空间复杂度：O(1)
